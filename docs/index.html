Install and connect

Use Node.js 18 or newer. Your API key stays in your own shell.

1

Install the command

npm install -g verifieddr

You can also run each command with npx verifieddr.

2

Add your API key

export VERIFIEDDR_API_KEY=vdr_your_key

Create a key in the VerifiedDR dashboard.

3

Check the connection

vdr account:usage

See your plan, API quota, and AI question space before you act.

Start with a clear answer

Each command has local help. Reading help uses no key or quota.

Find the best next step

Get a score, the main issue, and three actions for your site.

vdr analyze example.com

See your AI visibility

Review the buyer questions, rival brands, and cited pages.

vdr sites:visibility example.com

Check public authority

Read DR and trust data for a listed site. Try it with Wysera. 

vdr authority:lookup wysera.ai

Research a search term

See the DR level of the top results and your gap to that level.

vdr keywords:research "best crm" \
  --domain example.com

Find link partners

See matched sites and check each fit before you send a proposal.

vdr exchanges example.com

Read any command contract

Check flags, cost, output, and approval rules before a call.

vdr help sites:visibility

Use the same tools through MCP

Connect Claude Code, Cursor, or another MCP client to the remote VerifiedDR server. Each tool uses the same account and plan rules.

Read the MCP setup guide →
MCP setup 
claude mcp add --transport http verifieddr \
  https://verifieddr.com/api/mcp \
  --header "Authorization: Bearer vdr_your_key"
